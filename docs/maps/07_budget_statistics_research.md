# 방문객 예산 통계 조사 (DR-227·DR-228)

사용자 지시("예산은 실제 통계에 의거해서 해", 2026-10-31)에 따라 [02c I-215-a](02c_reaction_impl_map.md#i-215-a--추정-소득예산가격-민감도)(내국인 소득 → 예산)와 [I-213-a](02c_reaction_impl_map.md#i-213-a--외국인-관광객-집단과-배경-보행자)(관광객 하루 지출)의 가정 값을 공식 통계로 바꾼 과정이다. 사용자가 "전부 허락"해 원자료 8개를, 이어 "허락"해 가계동향조사 통계표 xlsx 2개와 국민여행조사 2025 통계편 PDF를 내려받아 읽었다. 목록·크기·해시는 [data/reaction-stats/README.md](../../data/reaction-stats/README.md), 채택한 값은 [DR-228](decisions.md#dr-228--소득예산관광객-지출의-통계-채택)이다.

## 1. 확인 수준

| 수준 | 뜻 | `statistics`로 쓰는가 |
|---|---|---|
| 1차 | 기관의 공식 보고서·보도자료·통계표 파일에서 숫자를 직접 읽음 | 예 |
| 2차 | 언론 기사, 증권사 리포트, 블로그 | 아니오 |

처음 조사(하위 에이전트 두 개)는 검색과 페이지 요약만 읽어 1차로 확인한 값이 하나뿐이었다. 그때 블로그에서 나온 직종별 월 임금(관리자 1,254.5만·서비스 187.7만·판매 311만 원 등)은 서비스가 판매보다 낮아 의심스러워 쓰지 않았는데, 원문과 대조하니 전체근로자(비정규직 포함) 기준 값과 모두 일치했다(서비스가 판매보다 낮은 것은 비정규직·시간제 비중 차이다). 이번에 원문 PDF·xlsx에서 직접 읽은 값만 아래에 적는다. 모든 값은 `scripts/extract_reaction_stats.py`가 뽑고 기대값과 다르면 중단한다.

## 2. 내국인 소득 (고용노동부 2025년 고용형태별근로실태조사, 2025.6, S02)

월 임금총액 = 정액급여 + 초과급여 + 전년도 연간특별급여/12(세전, 천원).

| 범주 | 전체근로자(정규직+비정규직) | 비고 |
|---|---|---|
| 전체 | 3,834 | 상용근로자 5인 이상은 4,482 |
| 직종: 관리자 / 전문가 / 사무 / 서비스 / 판매 | 12,545 / 4,761 / 4,516 / 1,877 / 3,108 | 통계표 6 |
| 직종: 농림어업 / 기능원 / 장치기계 / 단순노무 | 2,546 / 3,488 / 4,019 / 2,095 | 군인은 조사 제외 |
| 성별: 남 / 여 | 4,503 / 2,959 | 여 = 남의 0.657 |
| 연령: 29세 이하 / 30대 / 40대 / 50대 / 60세 이상 | 2,691 / 4,093 / 4,706 / 4,311 / 2,734 | 통계표 4 |
| 학력: 중졸 이하 / 고졸 / 전문대졸 / 대졸 / 대학원졸 | 2,016 / 2,850 / 3,792 / 4,669 / 6,686 | 통계표 3 |

상용근로자 5인 이상(임금구조 표)에는 직종 × 연령(10구간)과 직종 × 성별 표가 있어 직종 안 상대값을 구한다(예: 사무 남 5,748·여 4,088, 서비스 남 3,314·여 1,998천원). 직종 × 학력 교차표는 없다. 근거 JSON은 [wage_2025.json](../../data/reaction-stats/income/wage_2025.json).

**이전 가정 값과의 차이(통계 / 가정)**: 관리자 1,255만 / 600만 원, 사무 452만 / 320만, 서비스 188만 / 240만, 장치기계 402만 / 300만, 농림어업 255만 / 200만. 성별 계수는 가정 1.00인데 통계는 여/남 0.66. 연령은 전체 평균 대비 29세 이하 0.70(가정과 같음), 30대 1.07(가정 0.90), 40대 1.23·50대 1.12(가정 1.00), 60세 이상 0.71(가정 0.75). 학력 계수는 가정 0.80~1.25인데 통계 주변 값은 0.53~1.74다.

**구조 선택(U-14, 사용자 승인 DR-231)**: 주변 값을 그대로 곱하면 직종·연령·학력 구성이 겹쳐(예: 관리자는 나이 많고 학력이 높다) 분산이 부풀려진다. 그래서 직종 평균 × 직종 안 연령 상대값 × 직종 안 성별 비로 하고 학력은 적용하지 않는다(1.0). 한계: 직종 평균이 모든 연령·성을 평균한 값이라 인물의 구성이 근로자와 다르면 평균이 달라진다(테스트 E215-2가 ±25%로 확인하고 구현 뒤 조인다). 자영업·무직·학생은 이 조사에 없다.

## 3. 한 번 방문 예산

### 3.1 국민여행조사 2025 통계편 표 4-6 '1회 평균 국내여행 지출액'(S11, 1차)

여행 경험자 기준, 천원, 인쇄쪽 478(PDF 236쪽). 통계편 PDF(633쪽, 202MB)는 텍스트 층이 없어 쪽 그림을 읽어 옮겼고([domestic_trip_spend_2025.json](../../data/reaction-stats/income/domestic_trip_spend_2025.json)), 모든 행에서 국내전체 = w×당일 + (1−w)×숙박의 w가 0.40~0.80이고 전체 행이 0.579(보도자료 당일 비중 58.8%)로 정합한다.

서울 도착 당일여행(표 4-8-3, PDF 250쪽)의 서울 열은 전체 69천 원으로 전국 당일과 같지만 구분별 값은 표본이 작아 흔들린다(초졸 이하 89·고졸 61, 가구소득 100만 원 미만 42~600만 원 이상 76). 그래서 구분별 비는 전국 당일·숙박 열(표 4-6)에서 가져온다.

**성질**: 1회 지출은 소득에 둔감하다. 가구소득 닫힌 5구간(100~600만 원)의 로그-로그 기울기가 당일 0.122·숙박 0.121이다.

### 3.2 가계동향조사 2025(국가데이터처 통계표, S10, 1차)

소득 5분위별 가구 월평균(천원, 2025년 4/4분기, 시트 1.5): 소득 1,269 / 2,948 / 4,482 / 6,530 / 11,877, 소비지출 1,464 / 1,970 / 2,780 / 3,716 / 5,110, 가구원수 1.34 / 1.65 / 2.13 / 2.73 / 3.08. 재량 비목(음식·숙박+오락·문화+의류·신발+기타 상품·서비스)은 411 / 652 / 963 / 1,416 / 2,035다. 1인당으로 환산하면 소득 대비 재량 소비의 탄력성이 0.558이다. 1분위는 소비가 소득보다 크다(1,464 > 1,269, 흑자율 −38%). 2025 연간(전국 가구 월평균, 천원): 소비지출 2,939, 음식·숙박 465(15.8%), 오락·문화 175, 의류·신발 141, 기타 상품·서비스 250 — 기사로만 보던 15.8%가 1차로 확인됐다. 근거: [household_2025.json](../../data/reaction-stats/income/household_2025.json).

### 3.3 모델로의 번역(DR-230)

- comfort = 69,000원 × (소득/3,834,000)^0.122, limit = 221,000원 × (소득/3,834,000)^0.121. 하한은 가구소득 100만 원 미만 구간의 53,000·154,000원.
- 소득 없는 인물은 소득을 거치지 않고 직업 열 평균(학생 68,000/184,000, 전업주부 64,000/218,000, 기타 60,000/229,000)을 쓴다. 페르소나 원본에는 '무직'(서울 185,228명 중 67,302명)이 한 덩어리이고 학생·주부 항목이 없어 나이·성별로 나눈다(24세 이하 학생, 여성 25~64세 전업주부, 그 밖 기타).
- 가격 민감도 지수는 0.558(재량 소비의 소득 탄력성).
- 예: 소득 188만 원(서비스직 평균)이면 comfort 63,200·limit 202,700·민감도 1.49, 소득 1,255만 원(관리자 평균)이면 79,700·255,100·0.52. 소득을 10% 올리면 방문 예산은 1.2%만 오른다. 소득 수준(#12) 시나리오의 효과는 방문 예산이 아니라 가격 민감도로 나타난다.

**한계(U-15, 사용자 승인 DR-231)**: ① '넘기 싫은 큰 지출'을 숙박여행 1회 지출로 읽는 것은 해석이다. 표는 평균뿐이라 분위수(limit의 분포)는 원자료가 필요하다. ② 서울 거주자의 명동 방문은 일상생활권 안 외출이라 국민여행조사의 '여행' 정의와 다를 수 있다. ③ 가구소득 기울기를 개인 소득에 적용했다. ④ 소득 없는 인물의 소득 대리값(60·90·120만 원)은 개인 단위 통계가 없어 가정이다.

### 3.4 서울시 상권분석서비스(S09, 참고)

명동(명동거리) 상권 2025 결제 1건 평균 26,257원(10대 19,712~60대 이상 29,632원). 방문 1회 지출이 아니라 결제 1건이다. 예산 값에는 쓰지 않았다.

## 5. 받지 못한 것과 추가로 필요한 것 (U-13)

- 노인실태조사 2023(KIHASA 저장소): 사이트가 JavaScript 검증 쿠키를 요구하는 봇 차단 페이지를 먼저 보여 줘서 우회하지 않았다. 사용자가 브라우저로 받아 `data/reaction-stats/raw/05_kihasa_2023_elderly/`에 넣으면 읽는다.
- 국민여행조사 2025 원자료(국내여행) ZIP: 관광지식정보시스템 데이터 다운로드에 있다. 1회 지출의 분위수(limit의 분포)와 서울 방문 당일여행의 개인별 지출을 알 수 있다. 크기를 모르고 허락 목록에 없어 받지 않았다.
- 서울관광 실태조사 Raw Data xlsx(약 13MB, 선택): 명동 방문자의 쇼핑·식사 지출 교차용. 받지 않았다.
- KDI 경제정보센터의 가계동향조사 게시본은 비정상 접근 차단 페이지를 돌려줘서 쓰지 않았고(우회하지 않음) 국가데이터처 누리집의 첨부를 받았다.
- 이용 조건: 공공누리 유형 표기를 받은 파일에서 확인하지 못했다. 서울관광재단 파일은 저작권 문구만 있다.

## 6. 통계 → 모델 연결

[02c I-215-a](02c_reaction_impl_map.md#i-215-a--추정-소득예산가격-민감도)의 `income.yaml` v1.1과 [I-213-a](02c_reaction_impl_map.md#i-213-a--외국인-관광객-집단과-배경-보행자)의 `daily_spend_krw`에 반영했다. 라벨: 근로소득 계층·연령 상대값·성별 비·`ref_income_krw`·방문 예산(comfort·limit·소득 지수·직업 열)·가격 민감도 지수·관광객 하루 지출은 `statistics`, 군인 월 소득·소득 없는 인물의 소득 대리값과 무직 구분 규칙·명동 지출 몫·민감도 상하한은 `assumption`.
