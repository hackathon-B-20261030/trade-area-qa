# 명동 변수 10개 조사

조사일: 2026-10-31. 사용자의 요청 번호 2·3·4·6·9·11·12·14·15·16에 대한 공개 자료 및 기존 프로젝트 자료를 확인했다. 중심 대상은 명동 관광 상권이지만 각 출처의 실제 범위는 다르므로 아래에 따로 적는다. 벤치 숫자는 기존 OSM 추출 사각형과 명동 행정동의 교집합, 관광객 숫자는 출처에서 명동이라고 부른 지역의 통계다. 이 보고서는 자료 조사이며 시뮬레이션의 값·자료 계약을 수정하거나 자동 반영하지 않는다([DR-240](decisions.md#dr-240--명동-변수-자료-조사의-경계)).

## 검증 기록

- 공간·시설(E240-1~4): 항목 네 개를 대조했고, 중구의 길 폭·노점·미디어 시설 자료와 위 OSM·행정동 경계를 확인했다. `amenity=bench` 노드의 좌표에 대해 경계 포함 여부를 독립 재계산한 결과 사각형 13개, 그중 경계 안 12개였다. 경계 밖 노드 ID는 `6580139287`이다. 좌석 태그는 경계 안 5석 1개, 3석 8개, 미기재 3개다. 개수와 유효 폭·전수·자극도를 구분했다.
- 교통·방문·소득(E242-1~4): 세 항목과 명동역 상행 평일 시각의 간격을 대조했다. 외국인 수의 대상·기간과 세부 경계·중복 처리의 불확실성을 기록했다. 소득과 서울 관광 지출을 구분했다.
- 상점(E241-1~4): 세 항목과 상호별 영업시간·메뉴, 최저임금·환산 조건을 대조했다. 확인된 값은 사례 또는 법정 기준으로 표시했다. 보고서·관련 Map 외 시뮬레이션의 실행 자료는 변경하지 않았다.
- 통합: 사용자 요청 번호 10개 모두와 각 행의 단위·공간·시점·출처·해석 또는 미확인을 검토했다.
